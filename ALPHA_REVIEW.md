# Alpha Review Notes

## Boundary

Research Trail is deliberately separated from Search Check. Search Check addresses evidence retrieval; Research Trail addresses the developing epistemic record of an investigation.

## Corrections built into this package

The repository documentation makes several boundaries explicit that are easy to overclaim in an early prototype:

- provenance is not epistemic validity;
- a hash chain is tamper-evidence, not external immutability or identity verification;
- a traceability audit is not scientific certification;
- `prompted by` is not equivalent to `supports`;
- field-specific standards should be overlays, not a single universal checklist;
- AI origin does not imply truth, error, authorship, or responsibility.

## Alpha test target

The key test is whether researchers can record real iterative work without retrospectively forcing it into a linear or preregistered-looking narrative.

## Priority after live testing

Do not add features merely to increase surface area. The next design changes should be driven by observed failures in real investigations, particularly around multiple-parent relationships, state transitions, graph visualization, and evidence-package interoperability.
