# Changelog

## 0.1.0a1 — 2026-09-29

First guided static alpha.

### Added

- four use-case entry points;
- investigation setup from a starting question/problem;
- typed trail entries;
- explicit provenance/origin labels;
- separate epistemic-status labels;
- typed relationships between entries;
- source/reference field;
- chronological trail view;
- lightweight traceability checks;
- JSON, CSV, and HTML exports;
- SHA-256 entry hash chain;
- JSON Schema, synthetic example, and design/methodology documentation.

### Known limitations

- active work is session-local; export is required for persistence;
- relationships currently point to one earlier entry per entry;
- no graph visualization yet;
- no cryptographic signing or external immutable timestamping;
- no field-specific methodological overlays yet;
- no direct Search Check import yet.
